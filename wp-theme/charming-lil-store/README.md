# Charming Lil Store — WordPress + WooCommerce

Theme premium pour boutique de lingerie et pyjamas.

## Installation
1. Installer WordPress.
2. Installer et activer WooCommerce.
3. Compresser le dossier `charming-lil-store` en ZIP.
4. WordPress > Apparence > Thèmes > Ajouter un thème > Téléverser un thème.
5. Activer le thème.
6. WooCommerce > Produits : ajouter les produits, prix, images, tailles, couleurs, stock et catégories.
7. Apparence > Menus : créer le menu principal.

## Important
Le thème ne contient volontairement aucun catalogue produit codé en dur : les produits sont lus depuis WooCommerce, ce qui permet de les modifier depuis l'administration WordPress.
