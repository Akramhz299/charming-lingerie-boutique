# Charming Lil Store — WordPress + WooCommerce

Theme premium responsive pour boutique de lingerie et pyjamas.

## Installation du thème
1. Installer WordPress 6+.
2. Installer et activer WooCommerce.
3. Dans le dossier du projet, ouvrir `wp-theme/charming-lil-store/`.
4. Compresser le dossier `charming-lil-store` en ZIP (le ZIP doit contenir directement `style.css`, `functions.php`, etc.).
5. WordPress → Apparence → Thèmes → Ajouter un thème → Téléverser un thème.
6. Activer **Charming Lil Store**.
7. Réglages → Permaliens → Enregistrer les modifications.
8. WooCommerce → Réglages : configurer devise MAD, livraison, taxes et moyens de paiement selon le commerce.
9. WooCommerce → Produits : ajouter les produits, images, prix, stock, catégories et attributs (Taille, Couleur).
10. Apparence → Menus : créer le menu principal et le menu footer.
11. Apparence → Personnaliser → Charming Lil Store — Accueil : modifier le hero et la top bar.

## Produits
Le catalogue n'est pas codé en dur. Les produits proviennent de WooCommerce. Le client peut donc modifier depuis l'administration WordPress :
- titre
- description
- prix
- prix promotionnel
- images
- catégories
- stock
- tailles et couleurs via attributs/variations
- SKU

## Paiement à la livraison
Le texte marketing mentionne le paiement à la livraison, mais le moyen de paiement doit être activé/configuré dans WooCommerce → Réglages → Paiements.

## Images
Le thème utilise les images produits fournies par WooCommerce. Les visuels du catalogue original doivent être importés dans la médiathèque WordPress puis associés aux produits.

## Companion plugin
Le plugin `Charming Lil Store Companion` ajoute quelques améliorations WooCommerce spécifiques. Il est optionnel mais recommandé.

## Limites de cette version
Cette conversion fournit une base WordPress/WooCommerce fonctionnelle et éditable. Une traduction FR/AR complète, wishlist avancée, WhatsApp ordering et import automatique du catalogue original nécessitent des fonctionnalités supplémentaires ou des plugins dédiés.
